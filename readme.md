## 🔐 Encrypt & Decrypt

Tool untuk mengenkripsi dan mendekripsi file dengan standar keamanan tinggi.

### Fitur:
- **AES-256-GCM** — Algoritma enkripsi terkuat
- **PBKDF2** dengan 250.000 iterasi — Proteksi brute-force
- **Salt & IV** random 16/12 byte — Keamanan maksimal
- **100% offline** — Tidak ada data yang dikirim ke server
- **Web Crypto API** — Menggunakan kriptografi bawaan browser
- **Dark/Light Mode** — Nyaman digunakan
- **History** — Riwayat aktivitas selama sesi
- **Password Generator** — Buat password kuat otomatis

### Cara Pakai:
1. Buka **tools/encrypt-decrypt/**
2. Pilih file yang ingin dienkripsi atau didekripsi
3. Masukkan password (min. 8 karakter)
4. Klik Encrypt atau Decrypt
5. File akan otomatis diunduh
